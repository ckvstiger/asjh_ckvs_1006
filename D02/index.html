📱 1.3 網站化身手機 App：Flutter 跨平台專案與 Android APK 封裝

            
從前端 Web 跨界前進行動開發！透過 Google Flutter 框架打包成 Android 手機安裝包（.apk）

          

          Google Flutter × Dart
        


        
        

          
          
▲ 個人網頁 (HTML/CSS) 透過 Flutter 框架進行行動端封裝，編譯生成可安裝於 Android 手機的 student_profile.apk

        


        

          

            1
            
跨平台思維 (Cross-Platform)

            
Flutter 是由 Google 開發的開源 UI 工具包，讓開發者只需撰寫一份 Dart 代碼，就能同時編譯出 Android、iOS、Web、Windows 四大平台的原生應用程式！

          

          

            2
            
封裝方式與架構

            
A. 網頁容器封裝 (WebView)：透過 webview_flutter 套件直接在 App 內瀏覽載入個人網頁。
B. 原生 Widget 重構：使用 CircleAvatar 讀取 assets/MyQ.jpg，搭配 Card 與 Text 排版。

          

          

            3
            
打包產出 .APK 檔

            
執行命令 flutter build apk --release，編譯引擎自動將 Dart 程式與素材打造成 Android 安裝包（APK），學生可直接用手機掃描或傳輸安裝！

          

        


        
        
💻 Flutter 專案設定與 main.dart 代碼示範


        

          

            pubspec.yaml (資源引入設定)
          

          
flutter:

  assets:
    - assets/MyQ.jpg   # 👈 智光課堂規範：將生圖獲得的 Q 版頭像放入 assets 資料夾
