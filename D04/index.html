學習單 1 (學習單-1) 職群主題：職群概論

📌 商業與管理職群之基本介紹 📌 基本產品行銷 📌 中英文文書處理 📌 簡易記帳實務 📌 金融市場簡介 📌 國際貿易實務
💡 本單元 200 字核心重點整理
精華摘要 • 約 205 字

商業與管理職群旨在培育具備現代商務營運與數位資訊應用能力的專業人才。職群涵蓋商業經營、會計事務、資料處理及國際貿易等科別，主要核心能力包括：中英文輸入與文書處理、簡易記帳實務、產品行銷實務、門市銷售技巧及國際貿易基礎。學習者不僅能熟練商用軟體操作與帳務處理流程，更能掌握商品陳列、包裝設計與行銷企劃等實戰技巧，建立企業經營、金融流通及電子商務整合應用的核心素養，為未來升學與職場就業奠定堅實基礎。

✓ 職群科別：商經、會計、資處、國貿
✓ 四大能力：文書、記帳、行銷、貿易
✓ 概念區辨：資訊科屬於電機電子職群

D 資訊科 ✓ 正確解答
💡 正確解答：(D) ｜ 觀念深度剖析
商業與管理職群包含商業經營科、會計事務科、資料處理科、國際貿易科、電子商務科等。而「資訊科」屬於「電機與電子職群（工業類科）」，主要學習微電腦晶片、硬體裝修與電路控制，故不屬於商業與管理職群。
第 2 題
中文輸入法是屬於下列何者的核心能力？

B 銷售實務

中文輸入法（如注音、倉頡、無蝦米等）為商業數位建檔與公文製作的基本工具，屬於「中英文輸入」與商業文書處理範疇的核心技能。
第 3 題
下列何者不是商業與管理職群的核心能力？
A 中英文輸入

C 國際貿易實務
D 簡易記帳實務
💡 正確解答：(B) ｜ 觀念深度剖析
「基本電子應用」屬於電機電子職群或工業類課程的核心能力。商業與管理職群的核心實務能力聚焦於商業文書（中英文輸入）、財務會計（簡易記帳實務）、行銷企劃與對外經貿（國際貿易實務）。
第 4 題

記帳能力是會計學的基石，涵蓋原始憑證辨識、借貸分錄製作、日記簿登記至過帳與試算，屬於商管職群「簡易記帳實務」的核心能力。
第 5 題

學習單 2 (學習單-3) 職群主題：中英文文書處理

📌 1. 電腦簡介 📌 2. 中英文輸入
💡 本單元 200 字核心重點整理
精華摘要 • 約 208 字

認識電腦作業系統視窗元件與鍵盤操作是文書處理的基石。視窗環境包含標題列、最大化/縮小按鈕、邊框與顯示資訊的狀態列。標準鍵盤劃分為功能鍵區（F1~F12）、打字輸入區、編輯與方向鍵區及數字區。日常輸入需熟練快捷鍵：CapsLock 用於切換英文字母大小寫；PrtScr 鍵能快速截取全螢幕畫面至剪貼簿；Home 與 End 鍵可分別將游標瞬移至行首與行尾。掌握各功能分區與游標快速定位技巧，能大幅增進日常資料建檔與電腦操作的流暢度與生產力。

✓ 視窗元件：狀態列僅供提示無法調尺寸
✓ 鍵盤分區：F1~F12 位於最上方功能區
✓ 快速定位：End 到行尾、Home 到行首
📝 習題標準答案與深度試題剖析（共 5 題）
第 1 題
在視窗的基本元件中，那一個元件無法調整視窗的大小？
A 標題按鈕
B 控制功能表
C 視窗邊框
D 視窗狀態列 ✓ 正確解答
💡 正確解答：(D) ｜ 觀念深度剖析
視窗邊框可透過滑鼠拖曳拉寬或拉高；標題按鈕（包含最大化／還原鍵）及左上角控制功能表（內含「大小」、「最大化」等選項）都能調整視窗尺寸；而位於視窗底部的「視窗狀態列 (Status Bar)」僅用於呈現目前資訊（如游標位置、字數、縮放比），無法用於變更視窗大小。
第 2 題
若要複製整個螢幕的影像，要按什麼鍵？
A Tab
B PrtScr ✓ 正確解答
C Delete
D Ctrl
💡 正確解答：(B) ｜ 觀念深度剖析
鍵盤上的 PrtScr (Print Screen) 鍵 可將當前整個螢幕畫面截取並暫存於剪貼簿中，供使用者貼入 Word、小畫家或通訊軟體（若按 Alt + PrtScr 則僅截取目前使用中的視窗）。
第 3 題
若要將指標移到該行的最後位置，應使用鍵盤上那一個按鍵？
A Space
B Home
C End ✓ 正確解答
D Shift
💡 正確解答：(C) ｜ 觀念深度剖析
在文字編輯軟體中，按下 End 鍵 會將游標瞬間跳至目前這行的最末尾位置；若按下 Home 鍵 則是跳至該行的最開頭（行首）。
第 4 題
鍵盤上 CapsLock 鍵，有何功用？
A 轉換大小寫 ✓ 正確解答
B 跳上一頁
C 空一格
D 刪除
💡 正確解答：(A) ｜ 觀念深度剖析
CapsLock（Capitals Lock，大寫鎖定鍵），開啟時鍵盤指示燈亮起，輸入英文字母將固定維持為大寫狀態；再次按下關閉指示燈則恢復輸入小寫字母。
第 5 題
鍵盤的功能可分為四個區域，請問 F5 鍵，是屬於那一個區域？
A 功能區 ✓ 正確解答
B 打字輸入區
C 編輯鍵及方向鍵區
D 數字區
💡 正確解答：(A) ｜ 觀念深度剖析
標準鍵盤劃分為四大區塊：最上方一排 F1 ~ F12 屬於「功能鍵區（功能區）」；中間主要打字範圍為「打字輸入區」；右側有 Insert/Delete/Home/End/方向鍵的為「編輯鍵及方向鍵區」；最右側九宮格為「數字鍵區」。

學習單 3 (學習單-5) 職群主題：中英文文書處理

📌 1. 文書處理指法 📌 2. 輸入法特性比較
💡 本單元 200 字核心重點整理
精華摘要 • 約 206 字

中英文文書處理的基礎在於建立正確指法與熟悉輸入法特性。盲打定位以「基準鍵」為核心，左手依序置於 ASDF，右手置於 JKL;，由食指感受定位凸點。英文段落排版慣例首行空 5 個半形空格或使用 Tab 縮排；英文輸入切換大寫依賴 CapsLock 鍵。中文輸入法方面，倉頡輸入法按六書拆解字形，最符合漢字形體造字規則；注音輸入法普及且易學，但有不會念無法打、同音選字耗時等缺點。建立規範輸入習慣能大幅提升打字效率與文件精確度。

✓ 基準鍵配置：左手 ASDF，右手 JKL;
✓ 英文排版：段落開頭習慣空 5 個半形空格
✓ 造字拆解：倉頡輸入法最貼近中文六書造字
📝 習題標準答案與深度試題剖析（共 5 題）
第 1 題
在英文輸入時左手預設放在那四個按鍵上？
A ZXCV
B ASDF ✓ 正確解答
C QWER
D JKL;
💡 正確解答：(B) ｜ 觀念深度剖析
英打盲打的基本手指放置位置稱為「基準鍵（Home Keys）」，左手由小指至食指分別置於 A、S、D、F（其中 F 鍵表面有導航定位微凸點）；而選項 (D) 的 JKL; 則是右手的基準鍵位置。
第 2 題
英文的文章段落一開始要先空多少空白？
A 2
B 3
C 5 ✓ 正確解答
D 8
💡 正確解答：(C) ｜ 觀念深度剖析
在傳統英文文書排版規範與打字機書信標準中，每一段落起始處之首行縮排（Indentation）慣例為空 5 個半形空格（或按一次 Tab 鍵相當於 5 個半形字元寬度 / 0.5 英吋）。
第 3 題
那一種輸入法最接近中文造字規則？
A 注音
B 倉頡 ✓ 正確解答
C 無蝦米
D 內碼
💡 正確解答：(B) ｜ 觀念深度剖析
倉頡輸入法由朱邦復先生研發，將中國文字按「六書」原理與形體結構拆解為 24 個倉頡字根字母（如日、月、金、木、水、火、土、人、心等），其字形分析與拆碼最符合漢字造字本源。
第 4 題
何者不是使用注音輸入法的缺點？
A 不會念的字打不出來
B 要選字
C 一定要學會注音才可使用
D 同義的字太多 ✓ 正確解答
💡 正確解答：(D) ｜ 觀念深度剖析
注音輸入法是依音定字，其缺點為：遇到不識讀音的罕見字無法鍵入、同音異義字多需要選字耗時、需要預先熟稔拼音。「同義字多」是語言文字語意上的特質，並非注音輸入法的輸入設計缺陷。
第 5 題
請問鍵盤中的那個鍵，可以讓我們輸入英文時，全部出現大寫？
A ScrollLock
B F1
C CapsLock ✓ 正確解答
D Tab
💡 正確解答：(C) ｜ 觀念深度剖析
CapsLock（大寫鎖定鍵）按下亮燈後，輸入所有英文字母均會固定為大寫；若要在小寫狀態下偶爾輸入單一大寫字母，則可按住 Shift 鍵配合輸入。

學習單 4 (學習單-7) 職群主題：中英文文書處理

📌 1. Word版面配置 📌 2. 直書/橫書與段落設定
💡 本單元 200 字核心重點整理
精華摘要 • 約 205 字

Microsoft Word 為商業文書排版的主流工具，掌握其段落與版面功能至關重要。段落格式設定包含行距（單行、固定行高）與縮排（首行縮排、凸排），是調整文章閱讀節奏的核心；版面配置提供直書與橫書方向轉換，其中半形英文字在直書時會呈現橫臥，需特別留意。Word 內建完善的拼字、文法檢查及繁簡轉換功能，但不包含專業印刷之「四色分色輸出」。此外，熟悉鍵盤組合鍵如 Ctrl+Space 切換中英文，能讓公文與商務報告編排更具專業品質。

✓ 排版直書特性：半形英文轉直書會側倒橫臥
✓ 軟體極限：Word 無法直接做印刷四色分色
✓ 段落格式：縮排與行距均在「段落」對話框
📝 習題標準答案與深度試題剖析（共 5 題）
第 1 題
在 Microsoft Word 之「版面配置」內的「直書/橫書」功能選項中，下列哪種類型的資料無法達到「直書/橫書」的功能？
A 繁體中文字
B 簡體中文字
C 半形英文字 ✓ 正確解答
D 全形英文字
💡 正確解答：(C) ｜ 觀念深度剖析
Word 轉換為直書版面時，中文字及「全形英文字」皆會維持垂直正立向下排列；但「半形英文字」與半形數字在直書中會順時針旋轉 90 度呈橫躺倒臥排列，無法直接維持垂直端正的直書視覺效果（必須另外使用「橫向文字」設定）。
第 2 題
Word 沒有提供下列哪一種功能？
A 英文拼字檢查
B 英文文法檢查
C 將圖形四色分色輸出 ✓ 正確解答
D 中文簡體字與繁體字轉換
💡 正確解答：(C) ｜ 觀念深度剖析
Word 提供強大的校對工具（英文拼字與文法檢查）與中文繁簡字轉換功能；而「圖形四色分色輸出 (CMYK 分色印刷製版)」屬於專業美工印前排版軟體（如 Adobe InDesign、Illustrator）專屬功能，Word 並未具備。
第 3 題
在 Word 中要設定文字行距，應使用功能表中的哪一個選項？
A 「字型」選項
B 「段落」選項 ✓ 正確解答
C 「版面設定」選項
D 「項目符號及編號」
💡 正確解答：(B) ｜ 觀念深度剖析
行距（如單行間距、1.5 倍行高、固定行高）用於控制同一段落內各行文字之間的垂直間距，設定項目位於「段落」格式對話方塊中；「字型」則是設定字元大小、顏色與字距。
第 4 題
以下那個組合鍵可以切換中英文輸入？
A Ctrl + Shift
B Ctrl + Space ✓ 正確解答
C Ctrl + C
D Ctrl + Alt
💡 正確解答：(B) ｜ 觀念深度剖析
在 Windows 作業系統的標準輸入法規範中，Ctrl + Space（Ctrl + 空白鍵）是用來開啟／關閉中文輸入法（切換中英文輸入模式）的標準快速組合鍵；而 Ctrl + Shift 則用於輪替切換不同的輸入法（如注音、倉頡）。
第 5 題
在 Word 的「段落」功能中，可以完成下列哪種效果？
A 版面的設定
B 文字輸入法的設定
C 頁首/頁尾的設定
D 縮排與行距的設定 ✓ 正確解答
💡 正確解答：(D) ｜ 觀念深度剖析
Word 的「段落」功能核心就是用來微調段落屬性，包括首行縮排、凸排、左縮排、右縮排以及行距（固定行高、段落前／後間距）。版面設定在「版面配置」，頁首頁尾在「插入」，輸入法為系統層級。

學習單 5 (學習單-9) 職群主題：中英文文書處理

📌 1. 綜合應用 <課表製作> 📌 2. 快捷鍵與辦公軟體分工
💡 本單元 200 字核心重點整理
精華摘要 • 約 207 字

Office 辦公室軟體具備專業分工特點，應視任務需求靈活搭配。文字創作與課程表製作首選 Microsoft Word 文書軟體，善用快捷鍵能顯著加速編輯：Ctrl+C 負責複製、Ctrl+V 負責貼上、Ctrl+Z 能即時復原失誤；鍵盤 BackSpace 可刪除游標左側文字，Delete 則刪除右側文字。若遇大量詞彙替換，可利用「尋找與取代」批次完成。當面臨商業門市年終獲利率結算、排行榜製作與統計圖表呈現時，則應使用專門試算工具 Microsoft Excel 進行運算分析。

精華摘要 • 約 205 字

文書處理進階應用著重於圖文整合、輸出列印與商務自動化。製作卡片與圖文宣傳品時，按滑鼠左鍵可選取圖片並呼叫圖片工具調整版面。遇公司大量寄發邀請函或通知單需求，最便捷利器為「合併列印」，能串聯資料清單自動套印數百份個人化信件。掌握排版快捷鍵如 Ctrl+Enter 插入強制分頁符號，能避免按多個 Enter 造成排版位移；在列印設定對話框中，以「2-8」表示列印連續頁碼，以逗號區隔不連續頁碼，精準控管文件輸出品質。

✓ 分頁技巧：Ctrl + Enter 插入強制分頁符號
✓ 列印語法：「2-8」為連續頁，「2, 8」為個別單頁
